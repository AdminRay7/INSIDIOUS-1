## ✨ Features

### 🤖 **AI Chatbot**
- Smart AI responses using advanced language models
- Language detection (Swahili, English, etc.)
- Human-like conversation flow

### 🔒 **Security & Anti-Spam**
- Anti-link protection for groups
- Anti-scam message detection
- Anti-porn content filtering
- Automatic spammer banning
- Anti-call blocking
- Country-based auto-blocking

### 📱 **Auto Features**
- Auto-read messages
- Auto-react with custom emojis
- Auto-save contacts to database
- Auto-status view and like
- Auto-typing indicator
- Auto-bio with uptime

### 👥 **Group Management**
- Welcome/Goodbye messages
- Anti-link enforcement
- Anti-media restrictions
- Anti-tag protection
- Group lock/unlock (sleep mode)

### 🎨 **Interactive Features**
- Button-based menu navigation
- Scrollable command categories
- Real-time bot statistics
- Channel subscription enforcement
- Newsletter integration

### 📊 **Database**
- MongoDB integration
- User tracking and statistics
- Group management
- Channel subscriber tracking
